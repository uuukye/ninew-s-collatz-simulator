# ninew's-collatz-simulator



This is basically a p5.js program simulating the Collatz Conjecture. It is not proven yet, but there is no disproof to it.<br><br>
For a variable n, for each iteration the rules are:
* If `n` is **even**, divide it by 2: `n = n / 2`
* If `n` is **odd**, multiply it by 3 and add 1: `n = 3n + 1`

It's a Conjecture that states that for every positive integer n, after a number of iterations, n will eventually go to 1, (which goes to this 4, 2, 1, 4, 2, 1 loop)
